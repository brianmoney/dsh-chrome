dsh-agent settings

Address of the running dsh web. Open dsh UI opens this address in a normal tab; the browser bridge connects to ws://that-host/dsh-agent/bridge. Change it if dsh runs on another port, or if you reach it from another machine on your LAN.

The UI is deliberately not embedded in the side panel. dsh's session cookie is SameSite=Strict, and Chrome withholds it from a chrome-extension:// frame, so an embedded UI loads but can never authenticate. If the tab asks you to authenticate, open the tokenized URL that dsh web printed once — the session cookie persists after that.
