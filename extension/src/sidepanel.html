dsh-agent

The dsh web UI opens in a normal tab, not in this side panel. dsh issues its session cookie SameSite=Strict, and Chrome withholds that cookie from a chrome-extension:// frame — so a UI embedded here would load but could never authenticate: its requests would fail and nothing you changed would stick. A first-party tab has no such restriction.

Everything else still works from here. The bridge, the current-page feed, and the browser_* agent tools live in the extension's service worker and do not depend on this panel.
